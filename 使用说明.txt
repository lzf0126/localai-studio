================================================================
  本地 AI 助手 · LocalAI Studio   v3.0
  现代界面版 · 纯本机推理的离线大模型客户端
================================================================

【这是什么】

一个 Windows 桌面程序，用来管理和使用你本机部署的大模型。
界面用 HTML/CSS/JavaScript 编写，以无边框应用窗口运行，观感与
主流 AI 软件一致；生成与运算全部在你自己的电脑上完成。

【运行方式】

双击桌面快捷方式 → 程序会：
  1. 在 127.0.0.1:8799 起一个本地服务（托管界面 + 转发到 Ollama）
  2. 用 Edge/Chrome 的「应用模式」打开一个无地址栏的窗口
  3. 窗口关闭时自动退出

所以它看起来是个独立程序，实际上不需要装 Electron 之类的东西。

关于用哪个浏览器：程序会优先找 Chrome，找不到才用 Edge。
原因：实测 Edge 的「应用模式」窗口在这台机器上约 40 秒后会自行消失
（新配置目录触发的后台模式/启动加速会把它收走，加参数也无效），
而 Chrome 连续观察数分钟保持稳定。想强制指定可用：

    localai_web.exe --browser edge

【重要：它是客户端，不是全部】

本程序只包含「界面 + 服务」（约 12 MB）。
真正的模型计算由本机的 Ollama 后端完成。

【模型放在哪里 —— 不用设任何环境变量】

安装的时候已经让你选过一次模型存放目录，程序会自动记住。
你不需要设置环境变量，也不需要编辑任何配置文件。

  默认位置：D 盘存在就放 D:\LocalAI\models
            否则放 %LOCALAPPDATA%\本地AI助手\models

  以后想改：打开程序 →「设置」→「后端与联网」→ 改「模型存储目录」
            → 点「保存并重启后端」。就这样，不用重装。

安装目录里的东西：

    本地AI助手.exe      主程序
    bootstrap.ini       安装时选的路径（自动生成，不用手改）
    web\                界面文件（可以自己改，刷新窗口即生效）
    chats\              聊天记录、知识库、设置
    使用说明.txt         本文件

后端 Ollama（约 1.8 GB）需要单独安装一次，程序会自动在这些位置找它：

    %LOCALAPPDATA%\Programs\Ollama\
    C:\Program Files\Ollama\
    程序自身所在目录及其上级目录
    E:\depseekbushu

如果你把 Ollama 装在别处，设置一下环境变量 OLLAMA_DEPLOY_ROOT
指向它所在的那一级目录即可（这是唯一需要手动设的变量，正常用不到）。

【界面速览】

    左侧  ：新建对话 / 搜索 / 会话列表 / 模型市场 / 模型配置 / 设置
            底部显示后端状态和联网状态
    顶栏  ：模型选择 · 本地/云端切换 · 主题 · 背景设置 · 导出
    中间  ：对话区，消息气泡，思考过程可折叠，代码块可一键复制
    底部  ：输入框 + 读取网址 + 发送；下方实时显示内存与磁盘

【过渡动画】

页面切换是滑入+缩放+淡入，消息上浮入场，会话列表阶梯式滑入，
生成时有光标闪烁和三点指示器，按钮有悬停上浮与按下回弹。
不喜欢动画可在「设置 → 外观与个性化 → 界面」里一键全部关掉。

【背景与个性化】

「设置 → 外观与个性化」可以调：

    背景      无 / 8 种渐变 / 纯色（取色器）/ 图片（网址或本地上传）
    背景微调  暗度 0-90%、模糊 0-30px、铺满/完整/平铺
    主题      深色 / 浅色 / 跟随系统
    强调色    8 种，全局按钮与高亮同步变色
    其他      字体大小、气泡圆角、对话区宽度、毛玻璃开关

【联网功能】

顶部会实时显示是否联网与延迟。联网可用时：

  · 读取网页
      点输入框左边的「读取网址」，输入网址，程序会抓取网页正文
      （自动去掉导航/脚本/样式），作为附件挂到下一次提问上。
      抓取由本地服务完成，不受浏览器跨域限制。

  · 云端模型
      在「设置 → 后端与联网」里填 OpenAI 兼容接口，例如：
          接口地址  https://api.deepseek.com/v1
          API Key   sk-你的密钥
          模型名    deepseek-chat
      勾选「启用云端模型」后，顶栏的「本地 / 云端」按钮可以随时切换。
      云端也支持流式输出与思考过程显示。

  未联网时这些功能会给出明确提示，不会静默失败。

【模型市场】

1. 点左侧「模型市场」
2. 每张卡片显示：参数量、体积、运行所需内存、适配评级

     ✅ 推荐      内存充裕
     ⚠ 勉强      能跑，但别同时开大型程序
     ❌ 内存不足   会疯狂换页，慢到不可用

   评级是按你机器「当前可用内存」实时算的，不是写死的。

3. 点「下载并部署」，进度条实时显示百分比、速度、剩余时间
4. 下载完成自动注册，回「对话」页即可选用
   中途点「取消下载」不会白费——重试会从断点继续

【模型配置】

左侧列出所有已安装模型，选中查看详情（参数量、量化、上下文、
系统提示词、对话模板）。可以设为默认、删除，或者
「创建自定义模型」：选一个基础模型，写上系统提示词，
程序会把当前生成参数一起固化成一个新模型。

【本地知识库（RAG）】★ 最值得用的功能

让本机小模型「查着资料回答」，而不是「凭记忆瞎猜」。
7B 记不住的东西，给它资料它就能答对。

怎么用：
  1. 左侧「本地知识库」→「新建知识库」起个名字
  2. 「上传文件…」多选你的笔记/题解/模板；
     或「扫描目录…」填一个文件夹路径，递归导入里面的文本和代码
  3. 回对话页，点输入框左边的「知识库」按钮开启检索
  4. 正常提问即可。回答上方会显示「依据」了哪几个来源

面板里还有「检索测试」，输入问题直接看能检索到什么，
不调用生成模型，秒出结果，方便你确认资料有没有被正确索引。

嵌入模型默认用 qwen3-embedding:0.6b（600 MB，多语言）。
不要把「设置 → 后端与联网」里的嵌入模型换成 nomic-embed-text ——
它是英文向的，对中文排序会出错，实测完全不可用。

支持格式：.md .txt .py .cpp .java .js .json .csv .html .log .tex 等
          40 多种文本类扩展名，单文件最大 20 MB
不支持：PDF、Word、Excel（纯标准库解析不了，请先转成文本）

换嵌入模型时会自动重建索引，片段原文一直保留，不用重新上传。
知识库存在 chats\kb\ 下，删掉该目录即清空所有知识库。

【常见问题】

Q: 双击后没有任何反应
A: 先看日志（程序目录下 chats\localai.log）。
   若提示端口被占用，程序会自动顺延到 8800、8801…

Q: 窗口里显示「后端未运行」
A: 程序会自动尝试拉起 Ollama。若失败，检查部署根目录里是否有
   ollama\ollama.exe，或点顶栏的「重启后端」。

Q: 模型市场里下载失败
A: 需要联网。下载源是 Ollama 官方 registry，国内速度会波动，
   可点「取消下载」后重试，已下载的部分会保留。

Q: 读取网页失败，提示证书错误
A: 缺少 ca-bundle.pem。可从安装包目录复制一份到程序目录下。

Q: 提问后一直转圈
A: 大模型首次加载需要时间（1.5B 约 2-3 秒，7B 约 14 秒）。
   超过 1 分钟无输出，点「重启后端」试试。

Q: 聊天记录存在哪
A: 程序目录下的 chats\ 文件夹。会话存在浏览器本地存储里
   （绑定固定的浏览器配置目录，不会因为重启而丢失），
   设置则存在 chats\web-settings.json。

Q: 想改界面怎么办
A: 程序目录下的 web\ 文件夹（index.html / style.css / app.js）
   是优先加载的，改完刷新窗口即可，不用重新打包。

Q: 怎么彻底卸载
A: 控制面板「应用和功能」里卸载。卸载会询问是否删除聊天记录。
   注意：Ollama 后端和模型权重不会被卸载，需要手动删除部署根目录。
